# Architectural Context

RKGB follows:

```text
Presentation Layer

↓

Processing Engine

↓

Application Layer

↓

Domain Layer

↓

Repository Layer

↓

Infrastructure Layer
```

The Dependency Injection Framework belongs to the Infrastructure Layer but serves the entire application.

Every component should receive its dependencies through constructor injection.

No component should instantiate its own dependencies.

Responsibilities:

* Load configuration
* Initialize logging
* Build repositories
* Build infrastructure services
* Register application services
* Register buses
* Register pipeline infrastructure

# Service Lifetimes

Support three lifetimes.

Singleton

One instance for the application lifetime.

Examples:

* Configuration Manager
* Logging Manager
* Command Bus
* Query Bus
* Event Bus
* Plugin Registry

Scoped

One instance per execution scope.

Examples:

* Pipeline Context
* Request Context
* Correlation Context

Transient

New instance every resolution.

Examples:

* Command Handlers
* Query Handlers
* Validators
* Policies

The framework should allow future lifetime expansion.
